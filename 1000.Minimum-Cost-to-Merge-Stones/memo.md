## step1
30m以上考えて分からなかったので Hint として以下を見て解いた。合計で1h以上かかった。

k=2までは自力で考えられたが、k > 2 の答えに自力で辿り着けなかった。

思考過程：

k=2のときの全探索(カタラン数)の枝刈りを考える。
部分最適性が成り立つので、考える区間を徐々に短くしていけば良い。
漸化式は

dp[i][j] = min_{i \leq mid < j} (dp[i][mid] + dp[mid+1][j]) + sum(i, j)

k > 2 のときには次元をもう一つ増やして、区間をいくつのpileとみなすかを考える。漸化式は

2 <= num_pile <= k:

dp[i][j][num_pile] = min_{i \leq mid < j} (dp[i][mid][1] + dp[mid+1][j][num_pile - 1])

num_pile == 1:

dp[i][j][1] = dp[i][j][k] +  sum(i, j)
